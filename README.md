# سامری کامل اطلاعات بلیت‌ها

## سامری را کجا ببینم؟

**فایل [`index.html`](./index.html) را باز کنید.** این فایل صفحهٔ اصلی سامری است و جدول کامل اطلاعات بلیت‌ها را به‌صورت فارسی و راست‌چین نشان می‌دهد.

### بدون اجرای هیچ دستوری (نسخهٔ آنلاین)

پس از ادغام این تغییرات در شاخهٔ `main`، صفحه به‌طور خودکار با GitHub Pages منتشر می‌شود. در صفحهٔ مخزن وارد **Settings → Pages** شوید؛ زیر عنوان **Your site is live at** روی **Visit site** بزنید. اگر هنوز این پیام دیده نمی‌شود، در همان صفحه مقدار **Source** را روی **GitHub Actions** قرار دهید و اجرای گردش‌کار **Test and publish summary** را در زبانهٔ **Actions** بررسی کنید.

برای مشاهده روی کامپیوتر، پس از دریافت مخزن یکی از این روش‌ها را انجام دهید. هیچ نصب یا کتابخانهٔ اضافی لازم نیست؛ فقط Python 3 کافی است.

### روش پیشنهادی

ترمینال را در پوشهٔ پروژه باز کنید و فقط این دستور را اجرا کنید:

```sh
python open_summary.py
```

مرورگر به‌صورت خودکار باز می‌شود. اگر باز نشد، **همان نشانی که در ترمینال چاپ می‌شود** را کپی و در مرورگر وارد کنید؛ معمولاً `http://127.0.0.1:8000/index.html` است. اگر پورت ۸۰۰۰ مشغول باشد، برنامه خودش یک پورت آزاد انتخاب و نشانی درست را چاپ می‌کند. برای بستن برنامه در ترمینال `Ctrl+C` را بزنید.

### روش‌های جایگزین

1. مستقیماً روی فایل `index.html` دوبار کلیک کنید؛ یا
2. در همین پوشه فرمان زیر را اجرا کنید و سپس نشانی `http://localhost:8000` را باز کنید:

```sh
python -m http.server 8000
```

## چه چیزهایی داخل جدول است؟

جدول شامل این گروه‌هاست:

- مشخصات و شناسه‌های بلیت و قرعه‌کشی؛
- تاریخ خرید، تاریخ قرعه‌کشی، تاریخ اعلام نتیجه و مهلت دریافت جایزه؛
- شماره‌های بلیت، شماره‌های برنده، توپ ویژه، ضریب و ردهٔ برد؛
- قیمت بلیت، مبلغ جک‌پات، برد ناخالص، مالیات یا کسورات، برد خالص، ارز و وضعیت پرداخت.

> **وضعیت داده‌ها:** فایل‌های فعلی مخزن تصویر خوانای بلیت یا نتیجهٔ رسمی قرعه‌کشی را ندارند. به همین دلیل جدول آماده است، اما مقدار واقعی بلیت‌ها در آن درج نشده و هیچ شناسه، تاریخ، مبلغ یا شماره‌ای حدس زده نشده است. برای پرشدن جدول باید تصویر خوانای بلیت و نتیجهٔ رسمی قرعه‌کشی فراهم شود. پیش از اشتراک‌گذاری، بارکد و کد امنیتی قابل‌استفاده برای دریافت جایزه را بپوشانید.

## فایل‌های دیگر

- `devtools_what_can_you_help_me_with.md` — توضیح فنی و پاک‌سازی‌شده دربارهٔ منبع موجود.
- `open_summary.py` — اجرای یک‌دستوری سامری و بازکردن آن در مرورگر.
- `tests/test_static_content.py` — کنترل ساختار، کامل‌بودن ستون‌ها و نبود اطلاعات حساس.
